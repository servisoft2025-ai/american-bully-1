# AMÉRICAN BULLY — Web Prototype

Incluye:
- Páginas independientes: Inicio, El Box, Programación, Horarios, Coach, Contacto y FAQ.
- Área privada de atleta y Panel de Coach.
- Programación inicialmente VACÍA.
- Estructura mes → semana → lunes-sábado.
- Biblioteca privada preparada para movimientos y videos.
- Resultados y PRs preparados.
- Diseño responsive para teléfono.
- Botones de WhatsApp, Instagram y Google Maps.
- Imágenes proporcionadas: logo, coach y box.

IMPORTANTE:
La autenticación de este prototipo es solo demostrativa y usa localStorage. No debe utilizarse para proteger datos reales.
Para producción hay que conectar un backend/base de datos (por ejemplo Supabase/Firebase) con autenticación real, permisos ATLETA/COACH, almacenamiento de videos y reglas de seguridad.
